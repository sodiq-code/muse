   159→## 3. MINDS PLATFORM INTEGRATION MAP
   160→
   161→### 3.1 Platform Primitives We Use
   162→
   163→| Primitive | How Muse Uses It | Critical? |
   164→|-----------|-----------------|-----------|
   165→| **Soul (Identity)** | Muse's persistent identity as "creative teammate" | YES — Tier 1 |
   166→| **LTM (Long-Term Memory)** | Creator profile, voice, performance history, decisions | YES — Tier 1 |
   167→| **STM (Short-Term Memory)** | Active task context (current draft, current analysis) | YES — Tier 1 |
   168→| **Skills** | "Creator Memory Engine" custom Skill on Bazaar | YES — Tier 1 |
   169→| **Circles** | Muse ↔ Maker ↔ Guardian collaboration | YES — Tier 1 |
   170→| **Alarm Clock** | Overnight autonomous wake-up at 23:00 | YES — Tier 1 |
   171→| **Wallet** | Loyalty credential for top supporters | NO — Tier 3 |
   172→| **SSE Events** | Real-time UI updates from Mind activity | YES — Tier 1 |
   173→| **Cognition Credits** | Budget monitoring, balance checks | YES — operational |
   174→
   175→### 3.2 API Routes We Call
   176→
   177→| API Route | Purpose | Frequency |
   178→|-----------|---------|-----------|
   179→| `POST /v1/messaging/conversations` | Create conversation channels | Onboarding |
   180→| `POST /v1/messaging/send` | Send instructions to Minds | Every interaction |
   181→| `GET /v1/messaging/histories/{alias}` | Retrieve conversation history | Dashboard load |
   182→| `GET /v1/messaging/events` (SSE) | Real-time Mind activity stream | Always connected |
   183→| `GET /v1/minds/{mindId}` | Check Mind status, wallet info | Health checks |
   184→| `PATCH /v1/minds/{mindId}` | Enable/disable Minds | Control panel |
   185→| `GET/PUT/DELETE /v1/minds/{mindId}/skills` | Equip/unequip Skills | Setup + Bazaar |
   186→| `GET/POST/DELETE /v1/circles/{mindId}` | Manage Circle membership | Setup + changes |
   187→| `GET /v1/minds/{mindId}/cognition/usage` | Monitor cognition spend | Dashboard |
   188→| `GET /v1/minds/{mindId}/credits` | Check credit balance | Health checks |
   189→| `GET /v1/bazaar/skills` | Search Bazaar for Skills | Setup |
   190→| `GET /v1/bazaar/skills/{skillId}` | Get Skill details | Setup |
   191→
   192→### 3.3 Client Library Usage Pattern
   193→
   194→```typescript
   195→import { createMindsClient } from '@animocabrands/minds-client-lib';
   196→
   197→const client = createMindsClient({ builderApiKey: process.env.MINDS_BUILDER_API_KEY });
   198→
   199→// Core patterns we'll use:
   200→// 1. Send instruction to Muse
   201→const reply = await client.waitForReply(museAlias, instruction);
   202→
   203→// 2. Listen for real-time events
   204→const events = client.getEvents(); // SSE stream
   205→
   206→// 3. Retrieve memory/history
   207→const history = await client.getHistory(alias, { limit: 50 });
   208→
   209→// 4. Manage Circle (Muse ↔ Maker ↔ Guardian)
   210→await client.addCircleMembers(museMindId, { emails: [makerEmail, guardianEmail] });
   211→
   212→// 5. Equip custom Skill
   213→await client.equipSkills(museMindId, { ids: [creatorMemorySkillId] });
   214→
   215→// 6. Check cognition balance
   216→const balance = await client.getCognitionBalance(museMindId);
   217→```

   406→### 5.1 Prisma Schema
   407→
   408→```prisma
   409→// ============================================
   410→// MUSE — Creator Memory Database
   411→// ============================================
   412→
   413→generator client {
   414→  provider = "prisma-client-js"
   415→}
   416→
   417→datasource db {
   418→  provider = "postgresql"
   419→  url      = env("DATABASE_URL")
   420→}
   421→
   422→// ---------- CREATOR IDENTITY ----------
   423→
   424→model Creator {
   425→  id            String   @id @default(cuid())
   426→  name          String
   427→  email         String?  @unique
   428→  niche         String
   429→  bio           String?
   430→  avatarUrl     String?
   431→  
   432→  // Voice Profile (stored as JSON for flexibility)
   433→  voiceProfile  Json     @default("{}")
   434→  // { directness: 91, technicalDepth: 88, humor: 34, hype: 8, storytelling: 72, sentenceLength: 43, ctaIntensity: 28 }
   435→  
   436→  // Audience
   437→  primaryPlatform  String   @default("youtube")
   438→  audienceSize     Int      @default(0)
   439→  audienceType     String   @default("technical creators")
   440→  
   441→  // Preferences
   442→  tone           Json     @default("[]")  // ["direct", "technical", "conversational"]
   443→  avoid          Json     @default("[]")  // ["corporate language", "fake urgency"]
   444→  contentBoundaries Json  @default("[]")
   445→  schedulingPrefs   Json  @default("{}")
   446→  
   447→  // Metadata
   448→  isRealCreator  Boolean  @default(false)  // true = real creator, false = simulated
   449→  createdAt      DateTime @default(now())
   450→  updatedAt      DateTime @updatedAt
   451→  
   452→  // Relations
   453→  contentItems     ContentItem[]
   454→  metrics          ContentMetric[]
   455→  hooks            Hook[]
   456→  hookPatterns     HookPattern[]
   457→  decisions        CreatorDecision[]
   458→  memoryEvents     MemoryEvent[]
   459→  recommendations  Recommendation[]
   460→  drafts           Draft[]
   461→  approvals        Approval[]
   462→}
   463→
   464→// ---------- CONTENT & PERFORMANCE ----------
   465→
   466→model ContentItem {

   831→## 7. THE LEARNING LOOP — CORE ENGINE
   832→
   833→### 7.1 The Loop (This IS the Product)
   834→
   835→```
   836→CREATE → PUBLISH → OBSERVE → ANALYSE → UPDATE MEMORY → CHANGE STRATEGY → CREATE BETTER → NEXT ITERATION
   837→```
   838→
   839→### 7.2 Learning Engine Implementation
   840→
   841→```typescript
   842→// services/learning-engine.ts
   843→
   844→interface LearningInput {
   845→  creatorId: string;
   846→  contentId: string;
   847→  metrics: ContentMetric;
   848→  previousMemory: CreatorMemory;
   849→}
   850→
   851→interface LearningOutput {
   852→  memoryUpdates: MemoryUpdate[];
   853→  strategyChanges: StrategyChange[];
   854→  recommendations: Recommendation[];
   855→  evidenceChain: EvidenceChain[];
   856→}
   857→
   858→class LearningEngine {
   859→  async run(input: LearningInput): Promise<LearningOutput> {
   860→    // Step 1: OBSERVE — Gather raw signals
   861→    const signals = await this.observe(input);
   862→    
   863→    // Step 2: COMPARE — Against historical memory
   864→    const comparisons = await this.compare(signals, input.previousMemory);
   865→    
   866→    // Step 3: INFER — What changed and why
   867→    const inferences = await this.infer(comparisons);
   868→    
   869→    // Step 4: UPDATE — Modify creator memory
   870→    const memoryUpdates = await this.updateMemory(inferences);
   871→    
   872→    // Step 5: RECOMMEND — Next action with evidence
   873→    const recommendations = await this.recommend(memoryUpdates, input.previousMemory);
   874→    
   875→    return { memoryUpdates, strategyChanges, recommendations, evidenceChain };
   876→  }
   877→
   878→  private async observe(input: LearningInput): Promise<Signal[]> {
   879→    // Extract: hook pattern, engagement signals, retention curve, audience response
   880→    // Mark each signal as: observed | correlation | inference
   881→  }
   882→
   883→  private async compare(signals: Signal[], memory: CreatorMemory): Promise<Comparison[]> {
   884→    // Compare current performance against historical baselines
   885→    // "This contrarian hook outperformed your average by 18%"
   886→    // NOT: "Contrarian hooks are popular" (too generic)
   887→  }
   888→
   889→  private async infer(comparisons: Comparison[]): Promise<Inference[]> {
   890→    // Determine: What does this mean FOR THIS CREATOR?
   891→    // Statistical honesty: 
   892→    //   < 5 data points → confidence: "low"
   893→    //   5-15 data points → confidence: "medium"  
   894→    //   > 15 data points → confidence: "high"
   895→  }
   896→
   897→  private async updateMemory(inferences: Inference[]): Promise<MemoryUpdate[]> {
   898→    // Update: hook patterns, voice profile, performance baselines
   899→    // Every update is a MemoryEvent (audit trail)
   900→  }
   901→
   902→  private async recommend(updates: MemoryUpdate[], memory: CreatorMemory): Promise<Recommendation[]> {
   903→    // Generate: Next action recommendations
   904→    // EVERY recommendation MUST have:
   905→    //   - explanation (string)
   906→    //   - evidenceType (observed | correlation | recommendation)
   907→    //   - confidence (low | medium | high)
   908→    //   - dataPoints (number)
   909→    //   - supportingFacts (array)
   910→  }
   911→}
   912→```

  1211→```
  1212→22:00  Creator goes offline (detected via inactivity)

  1214→       → Reviews recent performance signals
  1215→       → Checks community sentiment (Guardian feed)
  1216→23:30  Muse delegates to Maker (via Circle)
  1217→       → Structured instruction with creator voice, winning hooks, topic
  1218→00:00  Maker produces draft
  1219→00:15  Muse evaluates Maker's output
  1220→       → Voice match score
  1221→       → Hook compatibility score
  1222→       → Alignment with creator preferences
  1223→00:30  Muse stores candidate draft (NOT published)
  1224→06:00  Muse prepares morning brief
  1225→       → Summary of overnight work
  1226→       → Drafts ready for review
  1227→       → New insights from learning engine
  1228→09:00  Creator reviews and approves/rejects
  1229→       → If approved → scheduled for publishing
  1230→       → If rejected → logged as CreatorDecision → memory updated
  1231→```

  1233→### 11.2 Approval Gate (Non-Negotiable)
  1234→
  1235→**Autonomous preparation + Human approval = Trust**
  1236→
  1237→```typescript
  1238→class ApprovalGate {
  1239→  async requestApproval(params: {
  1240→    action: string;
  1241→    description: string;
  1242→    autoSource: string;
  1243→    draftId: string;
  1244→  }): Promise<Approval> {
  1245→    // 1. Create approval record
  1246→    const approval = await db.approval.create({
  1247→      data: {
  1248→        ...params,
  1249→        status: 'pending',
  1250→      }
  1251→    });
  1252→    
  1253→    // 2. Create audit event
  1254→    await db.auditEvent.create({
  1255→      data: {
  1256→        action: 'approval_requested',
  1257→        actor: params.autoSource,
  1258→        isAutonomous: true,
  1259→        approvalId: approval.id,
  1260→      }
  1261→    });
  1262→    
  1263→    // 3. Notify creator (NEVER auto-publish)
  1264→    await this.notifyCreator(approval);
  1265→    
  1266→    return approval;
  1267→  }
  1268→}
  1269→```
