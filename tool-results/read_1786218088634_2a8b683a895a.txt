   161→   161→### 3.1 Platform Primitives We Use
   162→   162→
   163→   163→| Primitive | How Muse Uses It | Critical? |
   164→   164→|-----------|-----------------|-----------|
   165→   165→| **Soul (Identity)** | Muse's persistent identity as "creative teammate" | YES — Tier 1 |
   166→   166→| **LTM (Long-Term Memory)** | Creator profile, voice, performance history, decisions | YES — Tier 1 |
   167→   167→| **STM (Short-Term Memory)** | Active task context (current draft, current analysis) | YES — Tier 1 |
   168→   168→| **Skills** | "Creator Memory Engine" custom Skill on Bazaar | YES — Tier 1 |
   169→   169→| **Circles** | Muse ↔ Maker ↔ Guardian collaboration | YES — Tier 1 |
   170→   170→| **Alarm Clock** | Overnight autonomous wake-up at 23:00 | YES — Tier 1 |
   171→   171→| **Wallet** | Loyalty credential for top supporters | NO — Tier 3 |
   172→   172→| **SSE Events** | Real-time UI updates from Mind activity | YES — Tier 1 |
   173→   173→| **Cognition Credits** | Budget monitoring, balance checks | YES — operational |
   174→   174→
   175→   175→### 3.2 API Routes We Call
   176→   176→
   177→   177→| API Route | Purpose | Frequency |
   178→   178→|-----------|---------|-----------|
   179→   179→| `POST /v1/messaging/conversations` | Create conversation channels | Onboarding |
   180→   180→| `POST /v1/messaging/send` | Send instructions to Minds | Every interaction |
   181→   181→| `GET /v1/messaging/histories/{alias}` | Retrieve conversation history | Dashboard load |
   182→   182→| `GET /v1/messaging/events` (SSE) | Real-time Mind activity stream | Always connected |
   183→   183→| `GET /v1/minds/{mindId}` | Check Mind status, wallet info | Health checks |
   184→   184→| `PATCH /v1/minds/{mindId}` | Enable/disable Minds | Control panel |
   185→   185→| `GET/PUT/DELETE /v1/minds/{mindId}/skills` | Equip/unequip Skills | Setup + Bazaar |
   186→   186→| `GET/POST/DELETE /v1/circles/{mindId}` | Manage Circle membership | Setup + changes |
   187→   187→| `GET /v1/minds/{mindId}/cognition/usage` | Monitor cognition spend | Dashboard |
   188→   188→| `GET /v1/minds/{mindId}/credits` | Check credit balance | Health checks |
   189→   189→| `GET /v1/bazaar/skills` | Search Bazaar for Skills | Setup |
   190→   190→| `GET /v1/bazaar/skills/{skillId}` | Get Skill details | Setup |
   191→   191→
   192→   192→### 3.3 Client Library Usage Pattern
   193→   193→
   194→   194→```typescript
   195→   195→import { createMindsClient } from '@animocabrands/minds-client-lib';
   196→   196→
   197→   197→const client = createMindsClient({ builderApiKey: process.env.MINDS_BUILDER_API_KEY });
   198→   198→
   199→   199→// Core patterns we'll use:
   200→   200→// 1. Send instruction to Muse
   201→   201→const reply = await client.waitForReply(museAlias, instruction);
   202→   202→
   203→   203→// 2. Listen for real-time events
   204→   204→const events = client.getEvents(); // SSE stream
   205→   205→
   206→   206→// 3. Retrieve memory/history
   207→   207→const history = await client.getHistory(alias, { limit: 50 });
   208→   208→
   209→   209→// 4. Manage Circle (Muse ↔ Maker ↔ Guardian)
   210→   210→await client.addCircleMembers(museMindId, { emails: [makerEmail, guardianEmail] });
   211→   211→
   212→   212→// 5. Equip custom Skill
   213→   213→await client.equipSkills(museMindId, { ids: [creatorMemorySkillId] });
   214→   214→
   215→   215→// 6. Check cognition balance
   216→   216→const balance = await client.getCognitionBalance(museMindId);
   217→   217→```

   831→   831→## 7. THE LEARNING LOOP — CORE ENGINE
   832→   832→
   833→   833→### 7.1 The Loop (This IS the Product)
   834→   834→
   835→   835→```
   836→   836→CREATE → PUBLISH → OBSERVE → ANALYSE → UPDATE MEMORY → CHANGE STRATEGY → CREATE BETTER → NEXT ITERATION
   837→   837→```
   838→   838→
   839→   839→### 7.2 Learning Engine Implementation
   840→   840→
   841→   841→```typescript
   842→   842→// services/learning-engine.ts
   843→   843→
   844→   844→interface LearningInput {
   845→   845→  creatorId: string;
   846→   846→  contentId: string;
   847→   847→  metrics: ContentMetric;
   848→   848→  previousMemory: CreatorMemory;
   849→   849→}
   850→   850→
   851→   851→interface LearningOutput {
   852→   852→  memoryUpdates: MemoryUpdate[];
   853→   853→  strategyChanges: StrategyChange[];
   854→   854→  recommendations: Recommendation[];
   855→   855→  evidenceChain: EvidenceChain[];
   856→   856→}
   857→   857→
   858→   858→class LearningEngine {
   859→   859→  async run(input: LearningInput): Promise<LearningOutput> {
   860→   860→    // Step 1: OBSERVE — Gather raw signals
   861→   861→    const signals = await this.observe(input);
   862→   862→    
   863→   863→    // Step 2: COMPARE — Against historical memory
   864→   864→    const comparisons = await this.compare(signals, input.previousMemory);
   865→   865→    
   866→   866→    // Step 3: INFER — What changed and why
   867→   867→    const inferences = await this.infer(comparisons);
   868→   868→    
   869→   869→    // Step 4: UPDATE — Modify creator memory
   870→   870→    const memoryUpdates = await this.updateMemory(inferences);
   871→   871→    
   872→   872→    // Step 5: RECOMMEND — Next action with evidence
   873→   873→    const recommendations = await this.recommend(memoryUpdates, input.previousMemory);
   874→   874→    
   875→   875→    return { memoryUpdates, strategyChanges, recommendations, evidenceChain };
   876→   876→  }
   877→   877→
   878→   878→  private async observe(input: LearningInput): Promise<Signal[]> {
   879→   879→    // Extract: hook pattern, engagement signals, retention curve, audience response
   880→   880→    // Mark each signal as: observed | correlation | inference
   881→   881→  }
   882→   882→
   883→   883→  private async compare(signals: Signal[], memory: CreatorMemory): Promise<Comparison[]> {
   884→   884→    // Compare current performance against historical baselines
   885→   885→    // "This contrarian hook outperformed your average by 18%"
